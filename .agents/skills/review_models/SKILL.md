# Generate API Documentation

This skill instructs you to create API documentation for a specific feature, extracting request and response details directly from the codebase.

## Rules

Ensure every model have
1. Default constructor
2. dummy constructor
3. from json constructor
4. in from json, ensure there is no fallbacks values in parsing at all
